# The Entity Maincloud Postman Guide

## Environment
Import `TheEntity-Maincloud.environment.json` and set:
- `base_url` = `https://maincloud.spacetimedb.com/v1/database/the-entity-ty5fs`
- `player1_token` = blank
- `player2_token` = blank
- `owner_token` = your publisher account bearer token
- `room_id` = blank

## Body Mode Rules
- Reducers: `Body -> raw -> JSON`
- SQL reads: `Body -> raw -> Text`

## 404 Troubleshooting for `initiate_room`
Use exactly:
- Method: `POST`
- URL: `{{base_url}}/call/initiate_room`
- Header: `Content-Type: application/json`
- Body: `[{"some":"The Entity"}]`

Common 404 causes:
- Using `GET`
- Missing `/call/`
- Wrong reducer name (`initiateRoom` vs `initiate_room`)
- Wrong database id in URL

## What Is `room_id` For `join_room`?
`room_id` is generated by `initiate_room`.
Read it via SQL:

```text
select * from game_room order by created_at desc limit 1
```

Use first value from latest row as join payload:

```json
["AAAAAB"]
```

## Suggested Request Order (Round 1 Functional Flow)
1. `initiate_room`
2. SQL read latest `game_room` and save `room_id`
3. `join_room`
4. Optional admin setup calls
5. `generate_clue_manual_for_room` (round_1)
6. `generate_villain_speech_for_room`
7. `submit_terminal_for_room`
8. SQL reads for verification
